## Background

`scenes-prompt-v1.txt` describes four 336×88 px strips (shown 168×44 px, repeated horizontally, sewn on edge x): `field`, `siege`, `sortie`, `relief`. Output: `Resources/Wotr/Art/battle-scenes/<tryb>.png` with horizontal wrap (`wrapU` repeat). `Runtime/UI/Battles/BattleSceneArtwork.cs` loads the mode texture; no file leaves pass from the UI set.

## Replaced to painted bitmaps

1. Generate PNG according to the prompts, save without editing pixels, count SHA-256 and complete
   the manifest (`generator`, `source_filename`).
2. Set the cell rects from the alpha (>8, margin 4 px) to `layout-v1.json` and
   `battle-portraits-v1.json`; the scenes retain 336×88 px and wrap.
3. `Tests/Editor/PortraitArtworkTests.cs` checks keys, disconnection and import; after replacing
   four chip dumps.
